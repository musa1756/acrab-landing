# Скриншоты для обновлений

Сюда кладутся картинки, которые показываются в карточках релизов на главной.

- Имя файла — по версии: `1-3.png`, `1-4.png` и так далее.
- Пропорции — 16:10 (например 1600×1000). Другое соотношение тоже отрисуется:
  рамка `.release-media` обрезает картинку по `object-fit: cover`.
- После того как файл лежит здесь, в `index.html` замените блок
  `<div class="media-placeholder">…</div>` внутри нужного релиза на:

```html
<img src="/assets/changelog/1-3.png" alt="Что нового в 1.3" width="1600" height="1000">
```

Ссылки на несуществующие файлы валят `tools/check_site.py`, поэтому пока
картинки нет — оставляйте блок-заглушку, а не пустой `<img>`.
